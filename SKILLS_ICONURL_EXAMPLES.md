## Color Customization

Change the last part of the URL to customize colors:
- Green (default): `/16f2b3`
- White: `/ffffff`
- Blue: `/0096FF`
- Purple: `/8B5CF6`
- Red: `/EF4444`
- Orange: `/F97316`
- Yellow: `/EAB308`

**Example:**
```
Python (Green)  → https://cdn.simpleicons.org/python/16f2b3
Python (White)  → https://cdn.simpleicons.org/python/ffffff
Python (Blue)   → https://cdn.simpleicons.org/python/0096FF
Python (Purple) → https://cdn.simpleicons.org/python/8B5CF6
```

## Alternative: DevIcons

Pattern: `https://cdn.jsdelivr.net/gh/devicons/devicon/icons/{name}/{name}-{variant}.svg`

**Examples:**
```
Python      → https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg
JavaScript  → https://cdn.jsdelivr.net/gh/devicons/devicon/icons/javascript/javascript-original.svg

Docker      → https://cdn.jsdelivr.net/gh/devicons/devicon/icons/docker/docker-original.svg
```

Variants: `original`, `plain`, `line`, `original-wordmark`, `plain-wordmark`

## Adding New Skills with iconUrl

### Via Strapi Admin (Manual):
1. Go to **Content Manager → Skills**
2. Click **Create new entry**
3. Fill in:
   - **skillname**: e.g., "Tableau"
   - **iconUrl**: `https://cdn.simpleicons.org/tableau/16f2b3`
4. Click **Save** and **Publish**

### Via API (Automated):
```bash
curl -X POST "http://127.0.0.1:1337/api/skills" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "skillname": "Tableau",
      "iconUrl": "https://cdn.simpleicons.org/tableau/16f2b3"
    }
  }'
```

## Tips

1. **Search for icons**: Visit https://simpleicons.org/ and search for your skill
2. **Copy slug**: The slug shown is what you use in the URL (e.g., "nextdotjs" for Next.js)
3. **Consistent color**: Use `16f2b3` to match your site's green accent color
4. **Optional field**: You can leave `iconUrl` empty if the skill has a built-in icon
5. **Custom icons**: Upload your own SVG to Strapi Media Library and use that URL

## Viewing Results

After adding skills:
1. Refresh your frontend: `http://localhost:3000`
2. Scroll to the Skills section
3. Your custom icons should appear in the marquee!

## Troubleshooting

**Icon not showing?**
- Check if URL is correct (open it in browser)
- Make sure skill is **Published** in Strapi
- Hard refresh browser (Ctrl+Shift+R)
- Check browser console for CORS errors

**Want to remove custom icon?**
- Go to Strapi → Skills → Edit skill
- Clear the `iconUrl` field
- Save & Publish
- It will fall back to built-in icon (if available)
